# Coding-agent workflow

Read `AGENTS.md`, the owning contract, and relevant invariants before editing. Run `git status --short` first and preserve unrelated changes. Keep the diff scoped, avoid drive-by refactors, and record significant decisions in an ADR. For API changes update documentation and tests. Run only relevant checks, report exact commands and failures, and never imply CI or builds ran when they did not. Use Conventional Commits and do not merge PRs without explicit instruction.
